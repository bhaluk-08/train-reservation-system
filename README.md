# Train Reservation System

A simple Python-based train reservation system for booking and cancelling train tickets.

## Features

- Add trains and coaches
- Search available seats by class
- Book tickets
- Cancel bookings
- Track current reservations

## Run

```bash
python train_reservation.py
```

## Example output

```text
Train 101: Express 101
Available Sleeper seats for Delhi -> Mumbai: ['A1-01', 'A1-02', ...]
Booking created: {booking_id: '...', ...}
```
